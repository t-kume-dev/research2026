# Claude 用の会話メモ

- 作成日: 2026-10-27
- PC を移るとチャットが消えるので、会話の流れ・決まったこと・その理由を、Claude が次の会話で追えるように残す場所
- 本人が読んでもよいが、本人向けのまとめは `docs/progress/`（成果報告）と `docs/handoff.md`（やりかけのこと）が本体。
  ここはその裏の「なぜそうなったか」と「どこまで話したか」

## 使い方（Claude へ）

- **会話の最初に `log.md` の上のほうを読む。** 前回どこまで話したか、何が未決かが分かる
- 会話の中で何かが決まったら、`log.md` のその日の節に、決まったことと理由を書き足す。
  本人の言葉で理由が言われたら、それを残す（本人も覚えていないことがある）
- 決まったことが成果報告・マイルストーン・引き継ぎメモに関わるなら、そちらも直す。ここには「どこを直したか」を書く
- 新しい日は `log.md` の一番上に節を足す（新しい順）
- 古くなって間違いになった記述は、消さずに「→ YYYY-MM-DD に変更」と書き足す

## 置き場所の分担

| 知りたいこと | 見る場所 |
| --- | --- |
| 会話の流れ、決まったことの理由、未決のこと | `docs/claude-notes/log.md` |
| 今のマイルストーンと内訳 | `docs/milestones.md` |
| 次にやること、Git に入っていないもの | `docs/handoff.md` |
| その週の結果と数値 | `docs/progress/<日付>.md` の補足メモ |
| 研究全体の計画 | `docs/research-plan.md` |
