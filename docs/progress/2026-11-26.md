## 今週の目標

- **大きな目標**：M2「毎回取れる形になる」（1 回の来室で、MVC から KovaaK's 5 回まで、筋電・マウス・スコアを同時に記録して止まらずに通る）
- **小さな目標**：M2-2「筋電とマウスを同時に記録」：1 つのコマンドで筋電とマウスを同時に取り、KovaaK's の結果も取り込む

## やったこと

- 筋電とマウスを、1 つのコマンドで同時に記録できるようにした
  - マウスを裏で取りながら筋電を取る。どちらも同じ時計で開始時刻を残し、マウスの時刻を筋電の時刻（筋電の開始 = 0 秒）にそろえる
  - 同じ名前で、筋電・マウス・筋電とマウスを並べた図が残る。KovaaK's の結果も、記録のあとに自動で取り込む
- 画面録画も一緒に取れるようにした
  - 録画ソフト（OBS）を外から始め・止める。録画のファイルも、記録と同じ名前で同じフォルダに置く
- 1 回の来室を、1 つのコマンドで流せるようにした（M2-3「1 回の来室の流れ」の前半）
  - 信号の確認 → 部位の確認 → 安静 → 確認動作 → MVC → KovaaK's 5 回、の順に進む
  - KovaaK's は 1 回ごとに Enter で始まり、終わると筋電・マウス・録画・ゲームの結果がそろう
  - 途中で止まったときは、KovaaK's から再開できる
- 計測をどの PC でやるかを決めた：研究室のデスクトップ 1 台に、筋電・マウス・KovaaK's・録画をまとめる

## わかったこと

**M2-2「筋電とマウスを同時に記録」への答え：1 つのコマンドで、筋電とマウスを同じ時計で取れるようになった**

- 記録が最後まで止まらずに流れ、筋電・マウスのファイルが同じ名前でそろった
- 筋電の記録にも開始時刻を残すようにした（今までは残していなかった）。これで、マウス・録画・ゲームの結果の時刻を、すべて筋電の時刻に直せる
- 1 回の来室の流れのうち、KovaaK's を続けて遊ぶ部分（Enter → 記録 → 保存を 2 回）が止まらずに流れた。MVC までの部分は、前から使っている研究室の手順そのまま
- できなかったこと：研究室の機材（筋電のセンサ・録画ソフト）を、実際につないだ状態では、まだ通していない

**計測は 1 台の PC にまとめる必要がある**

- マウスの記録は、マウスをつないでゲームを動かしている PC でしか取れない
- 筋電も同じ PC で取れば、同じ時計で時刻を合わせられる。2 台に分けると PC 同士の時計が数十 ms ずれうるので、別に合わせる仕組みが要る
- 今のノート PC はゲームと録画を同時に回すには重いので、研究室のデスクトップを使う

## 補足メモ

- **確かめた範囲**：筋電は疑似信号（`--source sim`、実機と同じ形のデータを作るもの）で確かめた。録画ソフト（OBS）は、OBS の代わりの偽物でテストした。
  実機の筋電（Trigno）・本物の OBS ではまだ通していない。`visit` は KovaaK's の部分（`--skip-lab`）だけを疑似信号で 2 回流した。MVC までの部分は既存の `lab` の手順をそのまま呼んでいる（長い記録を省いただけ）。疑似信号での、マウスと筋電の開始時刻の差は −0.1 ms（マウスが先に始まる）
- **使い方**（`analysis/` で）
  - `python -m emgpipe play --duration 90 --name <名前>`：筋電とマウスを同時に 1 回。`--obs` で録画も、`--runs 5` で 5 回続けて（`<名前>_01`〜`_05`）
  - `python -m emgpipe visit`：1 回の来室。`lab` の手順（180 秒の長い記録は省く）→ KovaaK's 5 回（`kovaaks_01`〜`_05`、録画つき）。
    途中で止まったら `visit --skip-lab` で KovaaK's から。録画をしないときは `--no-obs`
- **残るファイル**（1 回ぶん、`data/raw/<日付>/`）：`<名前>.npz`（筋電）、`<名前>.csv`（マウス）、`<名前>.mkv` など（録画。拡張子は OBS の設定）、
  `<名前>.png`（筋電の包絡線とマウスの速さを縦に並べ、左クリックを縦線で引いた図）、`kovaaks/`（ゲームの結果の CSV）
- **時刻のそろえ方**：筋電・マウス・録画の開始時刻を、同じ時計（`time.perf_counter()`）で残す。
  `<名前>.npz` の meta の `mouse_offset_s`（マウスの時刻 + この値 = 筋電の時刻）、`video_offset_s`（録画の時刻 + この値 = 筋電の時刻）。
  ゲームの結果は PC の時計で残るので、マウスの開始時の PC の時計（`t0_unix`）で合わせる（M2-1 と同じ）
- **まだ確かめていないずれ**：筋電の開始時刻は「記録を始めた直後」の値で、センサから届くまでの遅れは入っていない。
  録画の開始時刻は「OBS が録画中になった」と分かった瞬間で、最初のフレームとは数十 ms ずれうる。どちらも実機で確かめる
- **マウスの記録の作り**：マウスは別のスレッド（裏で同時に動く処理）で取り、筋電はメインで取る。マウスは筋電より少し前に始め、少しあとに止める。
  録画があるときは、録画 → マウス → 筋電の順に始め、逆の順に止める
- **OBS の準備**：OBS の「ツール → WebSocket サーバー設定」でサーバーを有効にし、パスワードを `analysis/obs.json`（`{"password": "..."}`、Git の管理外）に書く。
  `pip install -r analysis/requirements.txt` で、OBS を操作するライブラリ（obsws-python）も入る
- **デスクトップに移すもの**：Python・リポジトリ（公開なので clone にログインは要らない）、`analysis/` の `DelsysAPI.key`・`DelsysAPI.lic`・`resources/DelsysAPI.dll`
  （Git の管理外なので USB などで写す）、Trigno のドライバ、Steam と KovaaK's、OBS
- **コード**：`analysis/emgpipe/play.py`（同時記録と図）、`obs.py`（録画）、`__main__.py` の `play`・`visit`。テストは `analysis/tests/test_pipeline.py` の `TestPlay`
