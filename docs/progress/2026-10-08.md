## 次やること

- MVC の取り方を次の 2 つにする。どちらも腕は机に乗せる
  - 伸展：手のひら下・握って、上から押さえてもらう（B）
  - 屈曲：机に向かって押し下げる
- 研究室で取り直す：確認動作（最初）→ B と一人用（H）を 2 回ずつ → 屈曲 → 最後に確認動作と B をもう 1 回
  - 伸展・屈曲とも、確認動作が 100 %MVC 以下に収まるか確かめる
  - 課題のあいだは十分休み、最後の B で疲れていないか見る
- 記録の前にセンサ番号と貼った位置を `sensors.json` に書き、反らす動きでどちらが伸筋側か確かめる
- 決まった課題を `analysis/emgpipe/calibration.py` の `DEFAULT_TASKS` に入れる

## 補足メモ

- **前回（10-01）の問題**：伸展の MVC を「机に固定した手を、自分の反対の手で押さえて反らす」で取ったら、デモで手首を反らしきっただけで伸筋側が約 350 %MVC になった。MVC が小さすぎると %MVC が 100% を超え、日をまたいだ比較の土台にならない
- **読んだ文献と MVC の扱い**

  | 文献 | MVC の扱い |
  | --- | --- |
  | Lacelle 2025 | 筋ごとの姿勢を表で明記。研究者が抵抗、約 3 秒 × 3 回 |
  | Forman 2023（博論）、Forman 2025 ×2 | 研究者が抵抗、2 ラウンド、声で励ます。手順は Forman 2020 を参照 |
  | Forman 2019（D. A. Forman 博論 3 章） | 筋ごとの表。伸筋側は前腕が親指が上の向き |
  | Forman 2020（Front Sports Act Living） | 力センサで手首の力の最大。手は開く、使わない手は机の上、3〜4 秒 × 2 回 |
  | Holmes 2022（PeerJ） | 筋ごとに 5 秒 × 2 回、30 秒以上休憩 |
  | Wang 2023 | 「Perotto 2011 に従った」のみ |
  | Park 2021、Prajapati 2024、Kuikkaniemi 2010 | MVC なし（−1〜1、標準化、その時々の最小・最大） |

- **Forman の手順をたどった経路**：Forman 2025 → Forman 2020（Sci Rep）→ Forman 2019 の Table 1。Forman 2019 は有料だが、著者の博論（2020、Ontario Tech、公開）の 3 章が同じ論文で、表 3.1 に同じ表がある
- **10-06 の記録**：`data/raw/2026-10-06/`（Git 管理外）。手順は `docs/lab/mvc_trial.md`、記録の経緯は同じフォルダの `notes.txt`
- **%MVC の見方**：確認動作のピーク ÷ その課題の MVC。100% 以下なら、その課題で全力を出し切れている。MVC は包絡線の 0.5 秒移動平均の最大
- **疲れの影響の向き**：疲れると全力の EMG は小さく出る。MVC が小さく出れば %MVC は大きくなる（不利になる）。B は疲れの影響があっても 100% 以下だったので、結論は変わらない。逆に、後に取った課題が小さいのは、課題のせいか疲れのせいか分けられない
- **A が日によって違う件**：同じ「反対の手で押さえる」やり方で、09-29 は確認動作（デモで反らしきった）が約 350%、10-06 は 96%。今のデータでは原因を決められない。センサの位置（10-06 は記録中に上下がわからなくなった）、押さえ方、確認動作の反らし方の違いなどが候補
