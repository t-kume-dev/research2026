# 研究室でやること：伸展の MVC の取り方を比べる

`literature/notes/MVC_protocols.md` の「後で試すこと」を、1 回の記録で全部試せるようにした手順。
上から順にやれば、記録のあと 2 つのコマンドでどの取り方がよいかがわかる。

## 何を決めるか

- 前回（09-29）は伸展の MVC が小さすぎ、手首を自由に反らしきるだけで伸筋側が約 350 %MVC になった
- 今回は候補の取り方を全部同じ日に取る。そのうえで次の 3 つを決める
  1. 他の人に抵抗をかけてもらうと、前回のやり方（反対の手で押さえる）より大きくなるか
  2. 伸筋の課題はどれを残すか（前腕の向き、握る・開く、尺屈・橈屈）
  3. 一人でやる方法（机の天板の裏を押す）で足りるか
- 判定は「確認動作（手首を自由に反らしきる）が 100 %MVC 以下に収まるか」

## 持ち物・準備

- **手伝ってくれる人 1 人**（抵抗をかけ、声をかけてもらう）。いない日は「一人のとき」の節へ
- センサは前腕の 2 か所（伸筋側・屈筋側）で足りる。6 か所付けた日に一緒にやってもよい
- 電極を付けたら、記録の終わりまで貼り直さない（貼り直したら最初から）
- `data/raw/<日付>/` を作り、`sensors.json` を置く（`docs/handoff.md` 4 章）
- Trigno Discover で全センサの波形が出ていることを確認する

## 共通のやり方

**基本の姿勢**
- いすに座り、前腕を机に置く。肘は 90〜110° くらい
- 手首から先は机の端から出す（手伝う人が手を持てるように）
- 力を出しているあいだ、手首はまっすぐのまま動かさない。手伝う人は、相手の力に合わせて押し返して止める
- 使わない手は、手のひらを上にして机の上に置く（何かを押さえるのに使わない）

**前腕の向き**
- 手のひら下（回内）：ふつうにマウスを持つ向き
- 親指が上（中間位）：前腕の小指側を机に置き、握手する向き
- 手のひら上（回外）：手の甲を机に置く向き

**1 試行**
- Discover で記録を始め、マーカーを付ける → 1 秒かけて力を上げ、全力で 5 秒 → 力を抜いてマーカー → 記録を止める
- 全力のあいだ、手伝う人は「もっと！もっと！」と声をかける（どの課題でも同じ調子で）
- 1 試行ごとに CSV で書き出す。ファイル名は下の表のとおり
- 試行のあいだは 30 秒休む。課題が変わるときは 60 秒休む
- 痛みが出たら、その課題は飛ばす（`notes.txt` に書く）

## 課題ごとのやり方

### 確認動作（`check_`）

- **伸展**：マウスを離し、前腕を机に置いたまま、手首を手の甲側に反らしきって 5 秒保つ。誰も押さえない（09-29 のデモと同じ動き）
- **屈曲**：同じように、手のひら側に曲げきって 5 秒保つ

### A 前回のやり方（`ext_self`）

- 手のひら下・握る。自分の反対の手で手の甲を押さえ、全力で反らす
- 比べるための基準として取る。これだけ使わない手を押さえに使う

### B 手のひら下・握って伸展（`ext_fist_pron`）

- 手のひら下・軽く握りこぶし
- 手伝う人は、手の甲（指の付け根より手首寄り）を上から押さえる
- 全力で手の甲側に反らす。「他の人に押さえてもらう」効果は A と B の差で見る

### C 親指が上・握って伸展（`ext_fist_neut`）

- 親指が上・握りこぶし。Forman 2019 の ECR（橈側手根伸筋）の課題
- 手伝う人は、手の甲側（このときは横向き）を押さえる
- 全力で手の甲側に曲げる（横向きに押す）

### D 親指が上・伸展＋小指側（`ext_ulnar_neut`）

- 親指が上・握りこぶし。Forman 2019 の ECU（尺側手根伸筋）の課題
- 手伝う人は、手の甲の小指側の角を押さえる
- 手の甲側に反らしながら、小指側（下）にも全力で押す

### E 親指が上・伸展＋手を開く（`ext_open_neut`）

- 親指が上・手を半分開く。手伝う人が両手で、指ごと手を包むように持つ。Forman 2019 の ED（総指伸筋）の課題
- 手の甲側に反らしながら、包まれた手を全力で開く

### F 手のひら下・伸展＋親指側（`ext_radial_pron`）

- 手のひら下・握りこぶし。Lacelle 2025 の ECR の課題
- 手伝う人は、手の甲の親指側の角を押さえる
- 反らしながら、親指側にも全力で押す

### G 手のひら下・開いて伸展（`ext_open_pron`）

- 手のひら下・手を開いて指を伸ばす。Lacelle 2025 の ED の課題
- 手伝う人は、指の付け根より先（指の背）を上から押さえる
- 指を伸ばしたまま、全力で反らす

### H 一人用・机の天板の裏（`ext_fixed_solo`）

- 手のひら下・握りこぶし。手の甲を机の天板の裏に当てる（肘は 110° くらい、手首はまっすぐ）
- 全力で上に押し上げる。反対の手は机の上に置き、机を押さえない
- 天板の裏に手が届かなければ、重い机の引き出しの下など、動かない物で代える（`notes.txt` に書く）
- 一人でやるときの声かけはないが、手伝う人がいる日は他と同じように声をかけてもらう

### I 手のひら上・握って屈曲（`flex_fist_sup`）

- 手のひら上・握りこぶし。Forman 2019 の FCR（橈側手根屈筋）の課題
- 手伝う人は、こぶしの手のひら側を上から押さえる。全力で手のひら側に曲げる

### J 手のひら上・相手の手を握って屈曲（`flex_grip_sup`）

- 手のひら上。手伝う人の指 2〜3 本を全力で握りながら、手のひら側に曲げる。Forman 2019 の FDS（浅指屈筋）の課題
- 手伝う人は、もう一方の手でこぶしを押さえて止める

## 一人のとき

手伝う人がいない日は、次の順で取る。他の人に抵抗をかけてもらう効果（B〜G）は別の日に回す。

`rest` → `check_free_extension` × 2 → `check_free_flexion` × 2 → A `ext_self` × 2 → H `ext_fixed_solo` × 2 →
屈曲（机に置いた手を下に押し下げる、`mvc_wrist_flexion_01`、`_02`）→ `check_free_extension_03`

## 記録のあと（解析）

`analysis/` で実行する。

```powershell
$env:PYTHONUTF8 = "1"
python -m emgpipe import-csv <日付>            # *.csv → *.npz
python -m emgpipe mvc-compare --session <日付>  # 課題ごとの比較。mvc_compare.csv にも保存
```

`mvc-compare` はチャネルごとに次の表を出す。上から MVC の大きい順に並び、最後の「全課題」が今のコード（`recalib`）が使う MVC。

```
前腕の上（伸筋群）
  確認動作のピーク: check_free_extension_02
  課題                       MVC     最大比      確認動作   試行ごと
  ext_open_neut          0.095    100%        92 %   0.091, 0.095
  ext_ulnar_neut         0.088     93%        99 %   0.088, 0.081
  ...
  ext_self               0.028     29%       320 %   0.027, 0.028
  全課題                  0.095    100%        92 %   0.095
```

（数値は見方の例）

- **最大比**：その課題の MVC ÷ 全課題の最大
- **確認動作**：確認動作のピーク ÷ その課題の MVC。100% 以下なら、その課題だけで足りている
- **試行ごと**：`ext_fist_pron` の 3 回目が 1・2 回目よりはっきり小さければ、後半は疲れていた

## 決め方

1. **伸筋側の「全課題」の確認動作が 100% 以下か**
   - 以下なら、候補の中に十分な取り方がある。2 へ
   - 超えるなら、どの取り方でも足りない。確認動作そのものを MVC の課題に加える
     （`check_free_extension_*.csv` をコピーして `mvc_free_extension_01.csv` などにし、`import-csv` からやり直す）
2. **A（`ext_self`）と B（`ext_fist_pron`）の差**：B がはっきり大きければ「他の人に押さえてもらう」効果があった
3. **残す課題**：伸筋側・屈筋側それぞれで、最大比が 90% 以上の課題を残す。少ない数で両方のチャネルをカバーできる組み合わせを選ぶ
4. **一人でできるか**：H（`ext_fixed_solo`）の最大比が 90% 以上で、確認動作が 100% 以下なら、今後は一人で取ってよい
5. 決まったら
   - `analysis/emgpipe/calibration.py` の `DEFAULT_TASKS` を決めた課題にする
   - `docs/handoff.md` 4 章の記録の表を、決めた課題に差し替える
   - 結果をその週の成果報告に書く（`mvc_compare.csv` の数値をもとに）
